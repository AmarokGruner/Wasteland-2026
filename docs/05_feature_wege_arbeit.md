# Feature: Wege, Arbeitspunkte & Straßennetz

## Source (FAQ 1.2, 1.4, 3.2.5, seed_gebaeude.py bautyp=Weg/Wegkreuzung)
- Buildings can ONLY be built on fields adjacent to road network
- Roads must connect to existing intersection (Kreuzung) – no isolated roads
- Building/demolishing costs Arbeitspunkte (AP)
- AP generated by population; road network increases AP max cap
- Max storable AP = 3× daily generation
- Road types (from seed): Feldweg (wegstufe 1), Kiesweg (wegstufe 3), etc.
- wegstufe sum → strassennetz value → affects Gesundheit
- Küstengebäude (nurkueste=1): only on outermost land ring adjacent to ocean

## Data Models
```python
ProvinceField: ..., has_road(bool), road_type_id, adjacent_fields[list[int]]
Province: ..., arbeitspunkte_current, arbeitspunkte_max, strassennetz(wegstufe_sum)
RoadNetwork: province_id, connected_field_ids[list[int]]  # BFS-connected set
```

## Core Logic
```
AP GENERATION (per 24h):
  daily_ap = population * 0.1  (base rate)
  ap_max = daily_ap * 3 * (1 + strassennetz/100)
  arbeitspunkte = min(arbeitspunkte + daily_ap, ap_max)

BUILD/DEMOLISH AP COST:
  road: baukostenmips-based, deduct from arbeitspunkte
  building: baukostenmips / 1000 AP (example formula)
  if arbeitspunkte < cost: reject with "INSUFFICIENT_AP"

ROAD CONNECTIVITY CHECK (before build):
  BFS from existing network → field must be reachable
  Kreuzungen connect perpendicular roads

STRASSENNETZ:
  strassennetz = sum(road_instance.wegstufe for all roads in province)
  → fed into Gesundheit formula in roundlogic

KÜSTE CHECK:
  if template.nurkueste: field must be in outer ring AND province.has_ocean_border
```

## Endpoints
```
GET  /province/{id}/roads → road network map + AP status
POST /province/{id}/roads/build {"field_id":int, "road_template_id":int}
POST /province/{id}/roads/auto-build {"road_type":str}  # consumes ALL AP
GET  /province/{id}/fields/buildable/{field_id} → includes road_connected check
```
